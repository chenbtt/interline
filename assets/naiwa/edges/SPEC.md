# 奶蛙贴边素材规格 v1

拖拽吸附到屏幕边缘时用的八张静态精灵图。只含美术，不含吸附逻辑。

## 一句话规则

**画布贴着屏幕的那条边，就是切口所在的那条边。**

接入时不需要记任何裁剪偏移量：把图按画布原点贴上去，抬到屏幕边缘即可。切口之外的像素全是透明，不会盖住底下的窗口内容。

## 文件清单

八张，`assets/naiwa/edges/` 下：

| 文件 | 被遮挡的一侧 | 画面上能看到的 | 对齐的屏幕边 | 可见像素包围盒 |
| --- | --- | --- | --- | --- |
| `edge-n.png` | 上（切 50%） | 腹部 + 双脚，头在边缘之上 | 上边 | (71, 0, 198, 112) |
| `edge-s.png` | 下（切 50%） | 头 + 举起的右手，身子在边缘之下 | 下边 | (58, 144, 193, 256) |
| `edge-w.png` | 左（切 50%） | 右半身，脸朝右（朝屏幕内侧） | 左边 | (0, 26, 70, 240) |
| `edge-e.png` | 右（切 50%） | 左半身，脸朝左（朝屏幕内侧） | 右边 | (186, 26, 256, 240) |
| `edge-nw.png` | 左（切 45%） | 头 + 右半身，斜着从角上探出来 | 左边 + 上边 | (0, 0, 77, 214) |
| `edge-ne.png` | 右（切 45%） | 头 + 左半身，斜着从角上探出来 | 右边 + 上边 | (179, 0, 256, 214) |
| `edge-sw.png` | 左（切 45%） | 头 + 右半身，从下往上斜探 | 左边 + 下边 | (0, 42, 77, 256) |
| `edge-se.png` | 右（切 45%） | 头 + 左半身，从下往上斜探 | 右边 + 下边 | (179, 42, 256, 256) |

包围盒是「可见像素」的 `(x0, y0, x1, y1)`，不是不透明矩形的边界——四个角上那组数字顶到 0 或 256，说明像素确实压到了画布边，没有留缝。

## 尺寸与格式

| 项 | 值 |
| --- | --- |
| 画布 | 256 × 256，正方形（四角要留斜探的空间，非正方形会切掉手） |
| 格式 | PNG，RGBA 8 bit/通道（32 位），sRGB |
| 背景 | 全透明，无投影、无描边、无地面阴影 |
| 单文件体积 | 18–21 KB |
| 可见内容 | 左右两张 70×214，上下两张 127×112 / 135×112，四角 77×214；覆盖率 13–16% |
| 与站立帧的比例 | 站立帧 192×208，贴边帧可见高 214 → 大 2.9%，吸附前后不跳大小 |

比例是按游戏帧（`manifest.json` 的 `frame_w/frame_h`）校准的，不是按屏幕分辨率。所以接入时**不要**再按窗口尺寸二次拉伸，用 256 画布 1:1 或等比例缩放即可。

如果要跟随「设置 → 奶蛙大小」，把整张图按同一系数缩放，切口照样落在缩放后的窗口边上——这条规则对缩放不敏感。

## 命名规范

```
edge-{dir}.png
```

- `dir` ∈ `n` `ne` `e` `se` `s` `sw` `w` `nw`，全小写，无下划线
- 前缀固定 `edge-`
- **`dir` 指的是被遮挡的那一侧，不是露出来的那一侧**。吸附到屏幕左边 → 左边被切 → `edge-w`
- 八向齐全；某个方向缺文件即视为不支持该方向，不做兜底

## 方向映射

| 吸附目标 | 文件 | 窗口怎么摆 |
| --- | --- | --- |
| 屏幕上边 | `edge-n` | 窗口上边 = 屏幕上边，沿 X 轴跟随拖动 |
| 屏幕下边 | `edge-s` | 窗口下边 = 屏幕下边，沿 X 轴跟随拖动 |
| 屏幕左边 | `edge-w` | 窗口左边 = 屏幕左边，沿 Y 轴跟随拖动 |
| 屏幕右边 | `edge-e` | 窗口右边 = 屏幕右边，沿 Y 轴跟随拖动 |
| 四角 | 对应的 `edge-{角}` | 两条边同时对齐，完全吸附不动 |

四角优先于四边：宠物中心到横边和竖边的距离**都**小于阈值时按角落处理，否则取更近的那条边。阈值取 64 px（画布 256 的 1/4）在 1080p 和 1440p 上都合适。

## 接入要点

1. 吸附态的窗口就是一个 256×256 的无边框透明窗口，内部只有这张图，没有气泡、没有绘制留白。气泡在吸附态里应该收起来——半个身子挂在墙上还顶着个对话框很奇怪。
2. 窗口位置由「对齐边」算出来，不需要读图里的像素：左/上贴边取 `0`，右/下贴边取 `屏幕宽 - 256`。
3. 拖离吸附位时切回站立姿态（`idle` 或 `running-*`），两者尺寸差 2.9%，肉眼看不出来，可以硬切。
4. 多屏时以宠物当前所在的屏幕为准（`QScreen.availableGeometry()`，不是 `geometry()`——后者含任务栏区）。
5. 打包前记得在 `Interline.spec` 的 `_PET_DATAS` 里补八行。`datas` 不展开通配符，漏了就只在打包版里表现为「图加载不出来」，源码跑一切正常。

## 重新生成

```bash
python make_pet_edges.py --prep      # 从 sheet.png 切站立帧，出 1024 参考图（图生图用）
#   → 把图生图结果（斜姿态、深灰底）放进 build/naiwa_edges/raw/
python make_pet_edges.py --build     # 抠图 → 摆位 → 八个方向裁切
python make_pet_edges.py --sheet     # 3×3 预览 → screenshots/pet-edges.png
python make_pet_edges.py --context   # 模拟桌面贴边 → screenshots/pet-edges-context.png
```

`--context` 那张是给评审看的：八只同时贴在屏幕四边四角，切口是否齐平一眼能看出来。

## 已知取舍

**`edge-n` 只有腹部和脚。** 蛙在屏幕上边之上，可见的必然是身体下半截，头被屏幕外裁掉。这是几何上唯一正确的结果，不是画漏了。四角那两组没这个问题，因为它们切的是竖边，头完整保留。如果顶边也想要「露脸」，需要一张专门俯身往下看的姿态（头在角色包围盒的下部），属于另一次作画，现有素材派生不出来。

**四角只切 45%，不是 50%。** 头在角色最上方，任何水平切口都会把头切掉，所以四角的遮挡全部交给竖边，垂直方向靠贴角（顶到画布边）来体现「在角落里」。代价是角的遮挡感比四边弱一档，45% 是「看得出被挡」和「保住脸」之间的平衡点。

**只有静帧，没有动画。** 吸附态目前是单张图，不做呼吸/飘动。如果需要，得按这套画布再出 3–4 帧，切面位置必须逐帧一致，否则会看到切口在抖。
