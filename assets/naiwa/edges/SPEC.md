# 奶蛙贴边素材规格 v3

吸附到屏幕边缘时用的精灵图：**八向 × 二相位，共 16 张**。会眨眼，身体不动。只含美术，不含吸附逻辑。

## 一句话规则

**画布贴着屏幕的那条边，就是切口所在的那条边。**

接入时不需要记任何裁剪偏移量：把图按画布原点贴上去，抬到屏幕边缘即可。切口之外的像素全是透明，不会盖住底下的窗口内容。

## 文件清单

```
edge-{dir}-{phase}.png        # 8 × 2 = 16 个，同一个目录
```

`dir` 是被遮挡的那一侧，`phase` 是 `base`（常态）或 `blink`（眨眼）。同方向的两张共用一张画布、一条切口，闪一下就切回来，不会抖。

| 方向 | 被遮挡的一侧 | 画面上能看到的 | 对齐的屏幕边 | base 帧可见包围盒 |
| --- | --- | --- | --- | --- |
| `n` | 上（整条背出画） | 头朝下 + 两只前爪扒住边缘，看得见的是**背**，没有肚皮 | 上边 | (34, 0, 221, 150) |
| `s` | 下（切 50%） | 头 + 举起的右手，身子在边缘之下 | 下边 | (58, 144, 193, 256) |
| `w` | 左（切 50%） | 右半身，脸朝右（朝屏幕内侧） | 左边 | (0, 26, 70, 240) |
| `e` | 右（切 50%） | 左半身，脸朝左（朝屏幕内侧） | 右边 | (186, 26, 256, 240) |
| `nw` | 左（切 45%） | 头 + 右半身，斜着从角上探出来 | 左边 + 上边 | (0, 0, 77, 214) |
| `ne` | 右（切 45%） | 头 + 左半身，斜着从角上探出来 | 右边 + 上边 | (179, 0, 256, 214) |
| `sw` | 左（切 45%） | 头 + 右半身，从下往上斜探 | 左边 + 下边 | (0, 42, 77, 256) |
| `se` | 右（切 45%） | 头 + 左半身，从下往上斜探 | 右边 + 下边 | (179, 42, 256, 256) |

包围盒是「可见像素」的 `(x0, y0, x1, y1)`，不是不透明矩形的边界——顶到 0 或 256 的那一侧，说明像素确实压到了画布边，没有留缝。同一方向的两张里这一侧**始终**是 0 或 256。

## 相位与播放

| 相位 | 内容 |
| --- | --- |
| `base` | 常态，睁眼 |
| `blink` | 眨眼，只换眼睛，姿态与 `base` 逐像素对齐 |

吸附态是**静止**的，只有眨眼：

```
base ──（停 2~4 秒，随机）──> blink ──（160 ms）──> base
```

眨眼不进任何循环，隔几秒闪一次就够。连续眨会显得神经质，按固定 2 秒更假；建议 2–4 秒之间随机，连眨两次的概率留低一点（比如 8%）。

不做呼吸是刻意的：顶边那张的呼吸动的是头，稍微给多一点就像在引体向上；侧姿态那点躯干胀缩在 256 px 上几乎看不出来。收益不值得两倍素材和一套呼吸状态机。

## 尺寸与格式

| 项 | 值 |
| --- | --- |
| 画布 | 256 × 256，正方形（四角要留斜探的空间，非正方形会切掉手） |
| 格式 | PNG，RGBA 8 bit/通道（32 位），sRGB |
| 背景 | 全透明，无投影、无描边、无地面阴影 |
| 文件数 / 总体积 | 16 张 / 367 KB，平均 22 KB |
| 可见内容 | 左右 70×214，下边 135×112，顶边 187×150，四角 77×214；覆盖率 14–34% |
| 与站立帧的比例 | 站立帧 192×208。除顶边外可见高 214（大 2.9%）；顶边按头宽对齐，见下 |

比例是按游戏帧（`manifest.json` 的 `frame_w/frame_h`）校准的，不是按屏幕分辨率。所以接入时**不要**再按窗口尺寸二次拉伸，用 256 画布 1:1 或等比例缩放即可。

如果要跟随「设置 → 奶蛙大小」，把整张图按同一系数缩放，切口照样落在缩放后的窗口边上——这条规则对缩放不敏感。

## 命名规范

```
edge-{dir}-{phase}.png
```

- `dir` ∈ `n` `ne` `e` `se` `s` `sw` `w` `nw`，全小写，无下划线
- `phase` ∈ `base` `blink`
- **`dir` 指的是被遮挡的那一侧，不是露出来的那一侧**。吸附到屏幕左边 → 左边被切 → `w`
- 八向二相位齐全；`blink` 缺文件就退回 `base`，不要留空窗

## 方向映射

| 吸附目标 | 文件前缀 | 窗口怎么摆 |
| --- | --- | --- |
| 屏幕上边 | `edge-n-*` | 窗口上边 = 屏幕上边，沿 X 轴跟随拖动 |
| 屏幕下边 | `edge-s-*` | 窗口下边 = 屏幕下边，沿 X 轴跟随拖动 |
| 屏幕左边 | `edge-w-*` | 窗口左边 = 屏幕左边，沿 Y 轴跟随拖动 |
| 屏幕右边 | `edge-e-*` | 窗口右边 = 屏幕右边，沿 Y 轴跟随拖动 |
| 四角 | `edge-{角}-*` | 两条边同时对齐，完全吸附不动 |

四角优先于四边：宠物中心到横边和竖边的距离**都**小于阈值时按角落处理，否则取更近的那条边。阈值取 64 px（画布 256 的 1/4）在 1080p 和 1440p 上都合适。

## 接入要点

1. 吸附态的窗口就是一个 256×256 的无边框透明窗口，内部只有当前这一帧，没有气泡、没有绘制留白。气泡在吸附态里应该收起来——半个身子挂在墙上还顶着个对话框很奇怪。
2. 换帧**只换图，不动窗口位置**。切口是靠窗口贴边实现的，重算位置反而会把切口推离屏幕边。
3. 窗口位置由「对齐边」算出来，不需要读图里的像素：左/上贴边取 `0`，右/下贴边取 `屏幕宽 - 256`。
4. 拖离吸附位时切回站立姿态（`idle` 或 `running-*`），两者尺寸差 2.9%，肉眼看不出来，可以硬切。
5. 多屏时以宠物当前所在的屏幕为准（`QScreen.availableGeometry()`，不是 `geometry()`——后者含任务栏区）。
6. 打包前记得在 `Interline.spec` 的 `_PET_DATAS` 里补 16 行。`datas` 不展开通配符，漏了就只在打包版里表现为「图加载不出来」，源码跑一切正常。

## 重新生成

```bash
python make_pet_edges.py --prep      # 从 sheet.png 切站立帧，出 1024 参考图（图生图用）
#   → 姿态图放 src/side/ 与 src/peek/，文件名带相位后缀
python make_pet_edges.py --build     # 抠图 → 摆位 → 八向二相位裁切
python make_pet_edges.py --sheet     # 八向 base 帧 3×3 预览
python make_pet_edges.py --context   # 模拟桌面贴边
python make_pet_edges.py --anim      # 胶片条 + GIF（验证眨眼用）
```

源图命名：`pose_x.png` 是基准，`pose_x@blink.png` 是眨眼变体（`@in` / `@out` 是呼吸变体，现在不生成成品，但留着）。全部按 512 存，进仓库不进包——放 `build/` 里的话（那是 gitignore 的）重新克隆后会静默退化，而退化只有肉眼看得出来。

`--anim` 出两张：`screenshots/pet-edges-frames.png` 是 8 行 × 2 列的胶片条，看切口有没有逐帧漂移；`screenshots/pet-edges-anim.gif` 是 w / s / n 三个方向「静一会儿突然眨一下」的循环。

## 已知取舍

**只保留眨眼，不做呼吸。** 顶边那张的呼吸动的是头——挂着的东西一上一下，稍微给多一点就像在做引体向上；压到温和又基本看不出来。侧姿态动的是躯干胀缩，256 px 上一共 8 px，远看是噪声。权衡下来呼吸不值得两倍素材加一套状态机，只留眨眼。想恢复：把 `make_pet_edges.py` 里的 `BREATH` 改成 `True` 重跑 `--build`，源图（`src/*/@in.png`、`@out.png`）还在。

**同一姿态的所有相位帧必须乘同一个缩放系数。** 这条是呼吸时代留下的，眨眼现在用不到，但改 `BREATH` 之后立刻会踩：吸气帧本来就比基准高 2%，逐帧各自缩到「固定高度」会把那一动抹平，播起来一动不动。`_scale()` 先用基准帧算 k，全体乘 k；另有一道预警，某帧高度偏离基准超过 15% 就报出来，那通常意味着源图分辨率不一致或者模型换了姿势。

**顶边要单独作画。** 蛙挂在屏幕上边之上，几何上可见的只能是身体下半截，头必然在屏幕外——四个角没这个问题，因为它们切的是竖边，头完整保留。所以顶边这张是另一次图生图：让模型画「趴在边缘上往下探，身体跑出画面上边被切平」，抠图后把可见像素顶到画布上边即可。

**提示词必须写清「看到的是背」。** 第一版只说了「往下探」，模型把头朝下之后顺手把奶白肚皮也画到了画面正中——从上后方看蛙，肚皮压在边缘上根本不该出现，这是视角前后矛盾。加上「必须看到背、纯黄、不许出现奶白肚皮」才干净。

**四角只切 45%，不是 50%。** 头在角色最上方，任何水平切口都会把头切掉，所以四角的遮挡全部交给竖边，垂直方向靠贴角（顶到画布边）来体现「在角落里」。代价是角的遮挡感比四边弱一档，45% 是「看得出被挡」和「保住脸」之间的平衡点。

**源图存 512 不存 1024。** 成品最大只有 224 px，512 大约是 2.3 倍采样，够用；1024 原图留在 `build/naiwa_edges/`（被 gitignore），要重出更精细的版本再从那儿取。16 张成品加 10 张源图共 2.1 MB 进仓库。
